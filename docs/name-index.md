The adjacent equipment-application lists in the AIM II brochure include IFF modes, radio families and link encryptors. Their column layout is not sufficient evidence to pair each algorithm with a particular application. The brochure also lists published primitives such as AES, DES, DSA and ECDSA, which illustrates why an equipment support list must not be copied wholesale into a Suite A membership list.
