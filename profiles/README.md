# Algorithm and scheme profiles

- [MEDLEY](medley.md) — A symmetric encryption primitive exposed through familiar block-cipher modes.
- [BATON](baton.md) — A block-oriented cipher with structured key representation and token-controlled initialization.
- [JUNIPER](juniper.md) — A historical block-cipher interface closely resembling BATON at the API boundary.
- [ACCORDION](accordion.md) — A versioned key-protection mechanism in the key-management path.
- [JOSEKI](joseki.md) — Confidentiality for loadable algorithm software in a protected execution environment.
- [WATARI](watari.md) — A confidentiality mechanism for security-software delivery.
- [FIREFLY / Enhanced FIREFLY](firefly.md) — Endpoint key establishment rather than the bulk data-processing stage.
- [SPONDULIX-S](spondulix-s.md) — A named KMI key-agreement option.
- [KM-TG signing schemes / SILVER LINING](software-signatures.md) — Authorization and authenticity checks for software updates.
- [SAVILLE](saville.md) — An older secure-voice lineage with a measurable implementation cost on AIM.
